# 인형 뽑기 🧸

집게를 좌우로 옮겨 인형 위에 맞추고 내려서 집은 뒤, 왼쪽 출구에 떨어뜨리는 크레인 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: **◀ ▶** 를 누르고 있으면 집게 이동, **뽑기!** 로 내리기. PC 는 `← →` 이동, `Space` 뽑기, `M` 소리.
- 정확히 맞출수록 잘 잡힙니다(인형 한가운데 기준). 큰 인형(🧸 30점, 💎 50점)은 점수가 높지만 올라가는 도중·옮기는 도중 미끄러질 수 있습니다.
- 쉬움 9번 · 보통 6번. 기회를 다 쓰거나 인형을 다 뽑으면 끝(남은 기회 ×10점 보너스).
- `logic.js` 규칙(`LOGIC_CRANE`), `game.js` 화면·입력·소리, `test/logic.test.js` (`node --test`).

## 균형 (시험용 봇, 300판)
가장 높은 인형 한가운데를 정확히 맞추는 봇의 평균: 쉬움 83점(5.6개), 보통 29점(2.4개). 사람은 이보다 덜 정확하므로 더 낮을 것입니다.
